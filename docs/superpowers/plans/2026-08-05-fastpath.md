# MP_FLAG_FAST_PATH Implementation Plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `MP_FLAG_FAST_PATH` so pools created with it skip header audit fields (magic/prev/next/location/backtrace) and active-list tracking, trading auditability for raw allocation speed.

**Architecture:** A create-time flag (`MP_FLAG_FAST_PATH = 1 << 18`) that makes `mp_alloc_internal` skip writing audit header fields, `mp_free` skip magic validation and active-list removal (via a shared `mp_free_stats_update` helper), and `mp_audit_heap`/`mp_isolate_bad_block` no-op. Counters (active_bytes/active_allocations/ops) are kept so leak checks still give a count verdict. Canary/poison/zero-on-alloc still work because `requested_size` is still written.

**Tech Stack:** C11 (gnu11), pthread, existing cmem codebase. No new files.

## Key invariants (from spec, source-verified)

- FAST_PATH pools still stamp: `alloc_type`, `slab_class`, `flags`, `requested_size`, `usable_size`, `raw_base`, `subpool`. These are REQUIRED for free-path dispatch, canary/poison sizing, TLSF routing.
- FAST_PATH pools skip: `magic`, `alloc_file/line/func`, `backtrace_depth`, `prev`, `next`. Since active-list tracking is off, prev/next are never read.
- `mp_free` magic validation (L2243) is skipped — a FAST_PATH pool cannot detect double-free/corruption; that is the documented tradeoff.
- `mp_isolate_bad_block` returns `false` under FAST_PATH (no magic to trust, no active list to remove from).
- `mp_audit_heap` returns `true` (healthy) immediately under FAST_PATH.
- `mp_check_leaks` works unchanged (count verdict on `active_allocations`); under FAST_PATH it reports count-only (no address walk because active_head is empty).
- `mp_alloc_loc` (L1897+) still works — it stamps location AFTER mp_alloc returns, only when the caller explicitly requests it. No change needed.

- [ ] **Step 1: Add mp_free_stats_update helper**

In `src/cmem_event.c`, immediately after `active_list_remove` (ends ~L1882), add:

```c
/**
 * @brief Update free-path accounting for one block.
 * Under MP_FLAG_FAST_PATH the active-allocation list is not maintained, so the
 * linked-list unlink is skipped; counters are always kept for leak-count verdicts.
 * @param pool   The memory pool.
 * @param header Block header being freed.
 */
static void mp_free_stats_update(memory_pool_t *pool, mp_block_header_t *header)
{
    if (!(pool->flags & MP_FLAG_FAST_PATH)) {
        active_list_remove(pool, header);
    }
    pool->stats.active_bytes -= header->requested_size;
    pool->stats.active_allocations--;
    pool->stats.total_free_ops++;
}
```

> Note: `active_list_remove` is defined just above (L1869-1882), so the helper can call it. `mp_free` (L2278+) comes later in the file — the helper must be defined before its call sites in Task 3 Step 3.

- [ ] **Step 1: Benchmark FAST_PATH vs THREAD_LOCAL_CACHE**

Create `/tmp/fastpath_bench.c`:

```c
#include "cmem.h"
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

#define COUNT 200000
static double now_sec(void)
{
    struct timespec ts;
    clock_gettime(CLOCK_MONOTONIC, &ts);
    return (double)ts.tv_sec + (double)ts.tv_nsec / 1e9;
}

static double run(int flags)
{
    memory_pool_t *pool = mp_create(32 * 1024 * 1024, flags);
    double t0 = now_sec();
    for (int i = 0; i < COUNT; i++) {
        size_t sz = 32 + (i % 224);
        void *ptr = mp_alloc(pool, sz);
        mp_free(pool, ptr);
    }
    double t1 = now_sec();
    mp_destroy(pool);
    return COUNT / (t1 - t0) / 1e6;
}

int main(void)
{
    double plain = run(MP_FLAG_THREAD_LOCAL_CACHE);
    double fast = run(MP_FLAG_THREAD_LOCAL_CACHE | MP_FLAG_FAST_PATH);
    printf("THREAD_LOCAL_CACHE: %.2f Mops/s\n", plain);
    printf("THREAD_LOCAL_CACHE|FAST_PATH: %.2f Mops/s\n", fast);
    printf("speedup: %.2fx\n", fast / plain);
    return 0;
}
```

Run: `gcc -O2 -std=gnu11 -D_GNU_SOURCE -I./include /tmp/fastpath_bench.c src/*.c -pthread -o /tmp/fastpath_bench && /tmp/fastpath_bench`
